# 10 Efforts

Personal notes plus a local reading wiki. This repository is private.

## On another computer

```bash
git clone https://github.com/tantran41/10-efforts.git
cd 10-efforts/Wiki_notes_on_the_go
npm install
npm start
```

Then open http://127.0.0.1:4321

The wiki reads every Markdown file in this repository. After `git pull`, refresh the browser.
